# Голосовой аватар — ссылка для тестирования

Открыть: https://averjahn.github.io/local-voice-avatar-demo/

GitHub Pages перенаправляет на полный прототип по HTTPS: https://voice-avatar.80-242-61-200.sslip.io/ . Python, распознавание речи, LLM и синтез выполняются на сервере прототипа. Эта страница не содержит моделей, пользовательских диалогов или кодов доступа.

Получите код входа у организатора. Разрешите микрофон и начните с «Проверить речь и губы». Для перебивания используйте наушники. Проверяйте по очереди: тестовый сервер рассчитан на один одновременный разговор. На слабом VPS распознавание и ответы могут занимать десятки секунд или минуты.
